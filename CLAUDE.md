# Low Vision Navigator

## Working agreements
- **Open a pull request as soon as work is ready. Don't ask first.** Base branch: `lvbranch` (the default). Before pushing, check whether the branch's previous PR was already merged; if so, bring the branch up to date with `lvbranch` and open a new PR.
- Before opening a PR, run `npm run build` and check visual changes in a browser at phone (390px) and desktop widths. Confirm the page doesn't scroll sideways.

## Project
- React + Vite site, prerendered at build time and served by a Node/Express server (`server/`) on Railway, with Postgres. See `README.md` for deployment, environment variables, the admin dashboard (PostHog analytics, DataForSEO SEO), and the AI assistant.
- `npm run typecheck` has 8 known unused-import errors that predate current work; don't treat them as new failures.
- `crm/` is a separate Railway service (EspoCRM, PHP + MySQL), not part of the website build. `scripts/crm-sync.mjs` loads the directory into it. See `crm/README.md`.
- `server/chat/site-pages.json` is regenerated by `npm run build`. Don't commit build-only changes to it.

## Brand assets (`public/`)
- `logo.png`: transparent wordmark. The footer shows it white with `brightness-0 invert`, so it must keep a transparent background.
- Favicon and icons: `favicon.ico`, `favicon-32.png`, `apple-touch-icon.png` (white background for iOS), `icon-192.png`, `icon-512.png`, `site.webmanifest`.
- `og-image.png`: 1200×630 social sharing image (logo on white). Edit it as an image; there is no generator script.
